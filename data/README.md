# Dictionary data

`ecdict_core.sqlite3` is generated from the MIT-licensed
[ECDICT](https://github.com/skywind3000/ECDICT) dataset by
`tools/build_dictionary.py`.  The generated runtime database keeps learner-
relevant English headwords and their inflected-form index.

ECDICT copyright and license notices are retained in `THIRD_PARTY_NOTICES.md`.
