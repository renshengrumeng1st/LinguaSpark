# LinguaSpark v2.4.0

## 更新内容

- PDF 全文问答使用独立浮窗，默认 `Alt+A` 呼出，可在设置中修改。结合全文文字、当前划句和已完成对话回答问题。
- 支持上传截图或 `Ctrl+V` 粘贴图片，预览、移除后再发送；结合 PDF 解释图表，支持保留截图的多轮追问。需要支持图片输入的模型。
- 可在“设置 → PDF 问答”中自定义回答风格。保存后从下一次提问起生效，留空沿用默认风格。
- 右侧栏专注于选中内容、译文和词组分析；词组区域占译文内容区的 45%。
- 翻译与问答支持 Markdown、离线 LaTeX 公式，代码块保留原样，复制回答保留原始文本。
- 页码引用支持背景色预览浮框、原文定位和临时高亮，保留缩放及横向位置。
- 修复框外松开鼠标后仍然拖选或自动滚动、失焦导致选区丢失、标记范围混入整页辅助矩形等问题。
- 修复 PDF 选区 `Alt+W` 翻译响应，以及带公式长回答在完成后反复重绘的问题。

## 使用说明

下载 `LinguaSpark-v2.4.0-windows-x64.zip`，完整解压后运行 `LinguaSpark.exe`。
保留同目录的 `_internal` 文件夹。升级前请退出托盘中的旧版本。

用户配置、学习记录和标记仍保存在本机 AppData。PDF 问答历史仅保留在打开的文档会话中，关闭文档或重启后不会恢复。

问答会发送可提取的 PDF 全文文字及用户主动附加的截图；不会自动解析或上传 PDF 中的全部图表。无文字层的文档也可附截图提问，此时模型主要依据截图解释。每次请求仍会发送全文；固定全文前缀是否命中缓存由模型服务决定。

发布包附带 SHA-256 校验文件。
