# PDF 全文提问框

目标：右侧栏仅保留选中内容、译文与词组分析，顶部为标记工具。问答改为 Alt+A 呼出的独立非模态圆角浮窗，默认显示简洁输入卡片，发送后展开回答和历史。上下文包含当前 PDF 的完整文字、发送时划中的句子、成功完成的对话历史和本次问题。暂不修改偶发滚动逻辑，不引入图像理解或自动检索替代全文。

实现顺序：

1. 用 Qt PDF 在工作线程提取全部页文字，保留空白页的页码；提取期间不阻塞阅读。超长、无文字、加密及读取错误明确反馈，不发送删减文档。
2. 新建独立的问答流式客户端和文档会话控制器，复用当前模型的协议适配。支持取消、重试、清空；仅成功完成的轮次加入后续上下文，关闭文档后销毁会话。
3. 翻译与问答独立显示并独立清空。Alt+A 在当前阅读器文档中呼出/收起问答浮窗，可在设置中修改并校验快捷键冲突；Esc 收起但保留草稿和历史。可拖动标题和调整窗口尺寸。Ctrl+Enter 或上箭头发送，提供停止、复制和清空；空闲状态隐藏提示。切换文档或隐藏阅读器时收起旧浮窗；关闭文档取消请求并销毁其会话。点击引用收起浮窗并将焦点返回 PDF。每轮保存发送时的划句，不因后来重新划句改变已发请求；无选区也可提问。模型文本安全显示，不执行外部链接或生成的 HTML。
4. 验证真实 PDF 文字提取、HTTP 请求与流式协议、错误和取消状态、标签隔离、页码导航、侧栏布局和原有 PDF 回归；更新 README。

长度边界：本地单篇全文最多 200,000 字符，完整消息最多 240,000 字符，单个问题最多 4,000 字符；此为本地提交保护，不代表模型实际容量。超过本地限制或服务端上下文窗口时提示选择长上下文模型、缩短文档或清空对话，不暗中裁剪。每次请求都带全文，可能增加耗时与费用。

用户发送问题时才调用当前模型。路径、文件指纹只在本地校验，不发给模型。新功能本次实现与验证，不自动打包、发布或推送。

后续调整：请求按“系统提示词 → 固定全文 → 已完成对话 → 当前划句与问题”排列，全文只在单次请求中出现一次，使相同文档和语言设置下的前缀不随追问或划句变化。保留全文提交和长度校验；实际缓存命中与加速依赖服务商支持，不新增厂商专用缓存参数。

引用定位：模型以 `[第 N 页｜原文短句]` 提供页码和引文，界面显示页码链接。点击后在该页 PDF.js 文字层按规范化文字查找唯一匹配，用独立的临时覆盖层高亮约 4 秒；兼容空白、大小写、常见引号标点、兼容字形和英文跨行断词。保留缩放与横向位置，已在视野内的原文不滚动，其余只做必要的纵向定位。目标页延迟渲染期间保留引用请求，不因自身定位产生的页面通知而清理高亮。没有引文、未匹配或重复匹配时只提示页面，不猜测位置。不改变浏览器选区或持久标记，缩放后重新计算文字位置，用户滚动、点击正文、新引用或超时清理覆盖层。引文悬停使用有宽度上限、可换行的原生浮框，背景跟随 PDF 阅读纸色且不抢焦点；不用系统默认的引文 title 提示。

公式改进：持久标记与临时引用均在绘制前合并相邻、重复和上下标字形矩形，保留独立行列。原生输出框继续承担选择、滚动与引用导航；用随包附带的 MathJax 3.2.2 在隔离的离线页面转换 LaTeX 为 SVG，再由 Qt SVG 生成高分辨率图像资源，保留原始 TeX 供复制。仅在首个完整公式出现时启动公式页面，不联网，不执行模型 HTML；异常和未完成公式保留原文。提示词要求标准公式定界，翻译缓存版本更新以免复用旧的扁平文字格式。验证数学渲染、流式闭合、宽度适配、安全回退、引用和高亮合并；不涉及发版。
