# LinguaSpark PDF 阅读模式设计

日期：2026-08-19

## 1. 目标

在不改变现有便捷翻译体验的前提下，为 LinguaSpark 增加独立的 PDF 阅读模式：用户打开 PDF 后在左侧连续滚动阅读，选择同一页内的文本并按 `Alt+W`，右侧尽快流式显示 LLM 译文。阅读器默认使用淡绿色护眼背景，支持切换其他浅色背景，并提供可持久化的简单文本高亮。

本功能只保存在本地 `feature/pdf-reader` 分支。源码验收通过前不打包、不推送。

## 2. 范围

### 包含

- 应用启动时显示模式选择：便捷模式或 PDF 阅读模式。
- PDF 文件选择、连续多页显示、鼠标滚轮滚动、缩放和页码状态。
- 鼠标拖动选择单页文本，`Alt+W` 触发专用快速翻译链路。
- 右侧翻译面板优先流式显示译文，随后补充词组分析，并支持复制和重新翻译。
- 淡绿色、米黄色、柔灰色、白色四种阅读背景。
- 黄色、绿色、粉色三种高亮标记及删除操作。
- 主题、最近打开目录和 PDF 标记保存在本地。
- 加密、损坏、无文本层 PDF 的明确错误提示。

### 不包含

- OCR、手写笔、文本批注、云同步、多人协作。
- 跨页文本选择。
- 自动整页或整本翻译。
- 修改 PDF 文件本身；标记只保存在 LinguaSpark 本地数据库。
- 本轮打包和 GitHub 推送。

## 3. 用户流程

1. 启动应用后出现简洁的模式选择窗口。
2. 选择“便捷模式”时打开现有小窗口，现有行为保持不变。
3. 选择“PDF 阅读模式”时打开约 `1180 × 760` 的阅读窗口；未打开文件时显示“打开 PDF”入口。
4. 打开文件后，左侧按页面纵向排列。滚轮滚动时自然跨页，工具栏显示当前可视页和总页数。
5. 用户在同一页拖动选择文本；选区使用半透明蓝色描边，并保留规范化后的选中文本。
6. 按 `Alt+W` 后，右侧在 50 ms 内进入“正在翻译”状态；缓存命中时直接显示结果，否则先逐步显示译文，再显示最多 5 个高价值词组及其中文含义。
7. 用户可把当前选区标为黄色、绿色或粉色；重新打开相同文件时恢复标记。
8. 托盘菜单提供“便捷模式”“PDF 阅读模式”和“退出”，可在两个窗口之间切换。

## 4. 界面结构

### 模式选择窗口

- 两张无冗余说明的模式卡片：“便捷翻译”和“PDF 阅读”。
- 关闭选择窗口等价于隐藏应用，托盘仍可再次打开模式选择。
- 首版每次冷启动都显示选择窗口，不增加“记住选择”开关。

### PDF 阅读窗口

- 顶部工具栏：打开文件、页码状态、缩小、放大、背景色、切换模式。
- 主体使用水平分割器：左侧 PDF 占约 65%，右侧翻译区占约 35%，允许拖动调整。
- 右侧只保留源文摘录、译文、词组分析、状态、复制、重新翻译和三种高亮按钮。词组区域在首个有效词组到达前保持隐藏。
- 窗口最小尺寸 `900 × 600`；首次尺寸 `1180 × 760`。

## 5. 架构

### 5.1 应用模式路由

`LearningAssistantApplication` 继续作为唯一组合根，新增 `ApplicationModeRouter` 管理模式选择窗口、现有 `MainWindow` 和新的 `PdfReaderWindow`。窗口按需创建，便捷模式不会导入或初始化 PDF 组件。

全局快捷键仍只注册一次。`Alt+W` 的路由规则为：

1. PDF 阅读窗口当前可见且拥有内部文本选区时，翻译该选区。
2. 否则沿用现有系统划词捕获与弹窗流程。

### 5.2 PDF 文档与连续视图

新增 `PdfDocumentSession` 封装 `QPdfDocument` 的加载状态、文件身份、页数和页面尺寸。新增 `SelectablePdfView` 继承 `QPdfView`，使用 `MultiPage` 模式实现原生连续滚动和渲染缓存。

由于 `QPdfView` 不提供完整的鼠标文本选择交互，视图增加一层轻量选择逻辑：

- `PdfPageLayout` 是不依赖 Qt UI 的纯几何模型，根据页尺寸、缩放、页间距、边距和滚动位置完成“视口坐标 ↔ 页码/PDF 点坐标”转换。
- 鼠标按下和拖动仅在同一页内建立起止点。
- `QPdfDocument.getSelection(page, start, end)` 返回文本、字符索引和边界多边形。
- `paintEvent` 在 Qt 已渲染页面之后绘制当前选区与本地高亮。
- 滚动和缩放只重新计算几何，不重新提取整本 PDF 文本。

项目新增精确匹配当前 Qt 版本的 `PySide6-Addons==6.10.1`，用于 `QtPdf` 与 `QtPdfWidgets`。该模块延续项目现有 Qt/PySide 技术栈，不引入第二套 PDF 引擎。

### 5.3 快速 PDF 翻译

新增 `PdfTranslationController`，与现有单词/句子控制器分离，但复用 `SettingsStore`、模型配置和 `LearningRepository`。新增专用的轻量流式请求方法，使用“译文在前、词组在后”的单请求协议，不等待完整 JSON：

- 只发送规范化后的选中文本、源语言和目标语言。
- 对支持的提供商关闭思考模式，温度设为 `0.1`，输出上限为 768 tokens。
- 模型先输出自然译文，再输出固定分隔符 `<<<PHRASES>>>`，最后每行输出一个 `英文词组 || 中文含义`，最多 5 行。
- 分隔符之前的内容收到后立即发出 `translation_partial`，右侧逐步追加译文；分隔符之后的完整行解析为结构化词组并发出 `phrase_ready`。
- 分隔符可能跨网络分片，解析器必须保留尾部缓冲；模型未返回分隔符时，所有内容均作为译文，不因格式偏差丢失结果。
- 新选择到来时取消上一请求，并用请求 ID 防止旧结果覆盖新选区。
- 缓存键包含提示版本、模型 ID、Base URL、源语言、目标语言和选中文本。
- 缓存保存最终译文和结构化词组；命中时不发起网络请求，目标是 50 ms 内显示完整结果。

PDF 翻译提示要求先忠实、自然地翻译所选内容，再挑选最多 5 个真正影响理解或值得学习的词组。译文和词组分析使用同一次请求，既避免第二次网络往返，也保证附加分析不会阻塞译文的首屏展示；不生成泛化学习建议或长篇语法说明。

### 5.4 背景主题

阅读主题由稳定的主题 ID 表示：

- `eye_care`：淡绿色 `#EAF4E2`，默认。
- `paper`：米黄色 `#F7F1E3`。
- `soft_gray`：柔灰色 `#EEF1F4`。
- `white`：白色 `#FFFFFF`。

主题同时应用于阅读区空白、窗口面板和 PDF 页面。PDF 页面通过轻量的半透明颜色混合降低纯白刺眼程度，不直接修改源文件。主题切换立即生效并写入设置。

### 5.5 本地标记

新增 `pdf_annotations` 表：

```sql
CREATE TABLE IF NOT EXISTS pdf_annotations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    document_key TEXT NOT NULL,
    page_index INTEGER NOT NULL,
    start_index INTEGER NOT NULL,
    end_index INTEGER NOT NULL,
    selected_text TEXT NOT NULL,
    color TEXT NOT NULL,
    bounds_json TEXT NOT NULL,
    created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_pdf_annotations_document
ON pdf_annotations(document_key, page_index);
```

`document_key` 使用规范化绝对路径、文件大小和修改时间生成稳定哈希，不读取整本文件计算 SHA-256，避免打开大文件时增加等待。文件内容或修改时间改变后视为新文档；移动文件后标记不会自动迁移。

颜色只允许 `yellow`、`green`、`pink`。添加标记需要有效选区；删除操作删除与当前选区字符范围完全相同的标记。边界使用 PDF 点坐标保存，缩放后仍能准确绘制。

## 6. 文本规范化与隐私

- 合并 PDF 行尾断词，例如 `trans-\nlation` 规范化为 `translation`。
- 普通换行转换为空格，连续空白压缩为一个空格。
- 选区为空或只含空白时不发请求。
- 单次选区最多 4,000 个字符；超出时提示用户缩小范围。
- 只把当前选区发送给已配置模型，不上传 PDF 文件、路径、其他页面或本地标记。

## 7. 错误处理

- 文件损坏或不支持：左侧保持空状态并显示“无法打开此 PDF”。
- 需要密码：提示用户输入密码；密码只在当前会话传给 `QPdfDocument`，不持久化。
- 页面没有文本层：允许阅读，但选择结束时提示“当前页面没有可选择文字，扫描版 PDF 暂不支持 OCR”。
- 未配置 AI：右侧显示设置入口，不影响 PDF 阅读与标记。
- 网络失败：保留源文和已有部分译文，显示可重试按钮。
- 快速连续选区：取消旧请求；只有最新请求 ID 可以更新右侧。
- PDF Addons 缺失：便捷模式仍可运行；进入 PDF 模式时显示依赖缺失提示。

## 8. 性能约束

- 使用 `QPdfView.MultiPage` 的内部页面渲染与缓存，不预渲染整本 PDF。
- 滚轮事件不触发文本提取、数据库写入或网络请求。
- 选区结束后才调用 `getSelection`，鼠标移动期间只更新几何预览。
- `Alt+W` 后 50 ms 内更新右侧状态并启动或命中缓存。
- 翻译请求复用 Qt 网络管理器；同一选区缓存命中时不访问网络。
- 词组分析与译文共用一次模型请求，解析词组不得阻塞已经到达的译文片段。
- 数据库继续使用 WAL 与短事务，标记写入不阻塞滚动。

## 9. 测试与验收

自动化测试覆盖：

- 页面布局坐标映射、滚动偏移、不同页尺寸和缩放。
- PDF 文本空白与断词规范化、长度限制。
- 快捷键在 PDF 内部选区与系统划词之间的路由。
- 翻译缓存、请求取消、旧请求隔离和流式片段顺序。
- 词组分隔符跨分片、有效词组解析、超过 5 个截断及缺少分隔符时的译文回退。
- 标记新增、读取、删除、文档身份变化和非法颜色。
- 默认护眼主题及主题持久化。
- 模式选择、PDF 窗口基础 UI 和现有便捷模式回归。
- 全量现有测试继续通过。

人工验收覆盖：

- 打开普通文本 PDF，滚轮连续跨页且缩放后选区位置正确。
- 选择英文句子后按 `Alt+W`，右侧快速出现状态并逐步显示中文译文；随后出现少量词组分析，但不会延迟译文首屏。
- 快速选择两段文本时不会显示第一段的迟到结果。
- 四种背景切换可见、重启后保留；三种高亮重开文件后恢复。
- 无文本扫描 PDF 可阅读但不会误发空翻译。
- 便捷模式的 `Alt+W`、小窗口、查词和复习功能不回退。

完成上述源码、自动化测试与人工启动检查后停止，不执行 PyInstaller 构建，不推送 `feature/pdf-reader`。
