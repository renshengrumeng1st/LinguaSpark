# LinguaSpark

LinguaSpark 是一款面向 Windows 的 AI 辅助英语学习助手。它既可以快速查询单词、翻译句子和图片，也可以在 PDF 文献中划选句子并即时获得译文与词组分析。

当前版本：`v2.3.0`

[下载 Windows 64 位发布包](https://github.com/renshengrumeng1st/LinguaSpark/releases/download/v2.3.0/LinguaSpark-v2.3.0-windows-x64.zip) · [版本发布记录](https://github.com/renshengrumeng1st/LinguaSpark/releases)

## 主要功能

### 便捷学习模式

- **单词查询**：输入单词后自动查询本地词典，优先显示音标、词性、释义和词形，不必等待网络。
- **AI 助记**：随后由 AI 补充通俗解释、近义词、常用搭配、例句和记忆提示。
- **句子翻译**：输入句子后按 `Ctrl+Enter`，流式显示 AI 译文，再补充关键表达和学习提示。
- **图片翻译**：直接粘贴剪贴板图片，再按 `Ctrl+Enter` 识别并流式显示译文。
- **全局划词翻译**：在其他应用中选中文字后按 `Alt+W`，LinguaSpark 会优先通过 Windows UI Automation 读取选区，并在失败时安全回退到剪贴板。
- **发音**：支持离线 Windows 本地语音，也可配置音质更自然的 Azure Neural TTS。
- **学习与复习**：可以收藏内容、将单词加入学习计划，并使用“不记得 / 模糊 / 记得”完成间隔复习。
- **开机自启**：可在常规设置中开启，登录 Windows 后自动驻留托盘。

### PDF 阅读模式

- 同时打开多个 PDF，通过顶部标签快速切换。
- 鼠标滚轮连续阅读，支持 `50%–300%` 缩放、适合宽度和 `Ctrl + 滚轮` 缩放。
- 使用 PDF.js 原生文字层选择文本；拖动选区时直接显示蓝色高亮。
- 选中句子后按 `Alt+W`，右侧优先显示流式译文，随后补充最多 5 个词组分析。
- 支持黄色、绿色和粉色标记，也可以移除当前标记。
- 默认淡绿色护眼背景，可切换米黄、柔灰或白色主题。
- PDF 窗口默认最大化；点击“专注阅读”后只保留原文和译文栏，按 `Esc` 退出专注模式。
- 每个 PDF 标签独立保留滚动位置、缩放、选区、译文、词组分析和标记。

## 安装与启动

### 环境要求

- Windows 10 或 Windows 11（64 位）
- 一个兼容 OpenAI API 格式的 AI 模型服务

### 使用 Windows 发布包

1. 下载上方的 `LinguaSpark-v2.3.0-windows-x64.zip`。
2. 将压缩包完整解压到固定目录。
3. 双击 `LinguaSpark.exe` 启动，无需安装 Python。

请保留 EXE 同目录下的 `_internal` 文件夹，不要单独移动 EXE。发布包内已包含本地词典与 PDF 阅读组件。

升级时退出托盘中的旧程序，再使用新解压的完整目录。用户配置和学习数据保存在 AppData；如果更换了安装路径，请在新版本的常规设置中重新开启开机自启。

### 从源码运行

源码运行需要 Python，建议使用 Python 3.11 或更高版本。

克隆项目：

```bat
git clone https://github.com/renshengrumeng1st/LinguaSpark.git
cd LinguaSpark
```

首次使用先安装依赖：

```bat
setup.bat
```

安装完成后启动：

```bat
run.bat
```

启动时可以选择“便捷模式”或“PDF 阅读模式”。程序关闭窗口后仍会驻留在系统托盘，可通过托盘菜单直接进入便捷模式、PDF 阅读模式、今日复习或设置。

### 开机自动启动

打开“设置 → 常规”，勾选“开机时自动启动 LinguaSpark”，点击“保存常规设置”。此设置仅作用于当前 Windows 用户；自动启动时不弹出模式选择窗口，可通过系统托盘或快捷键打开界面。取消勾选并保存即可关闭。

## 首次配置 AI 模型

1. 打开“设置 → AI 模型”。
2. 点击“添加”，选择模型厂商以填入常用 `Base URL`，再输入 `API Key`。支持 LongCat、DeepSeek、百炼、智谱、Kimi、硅基流动、火山方舟、OpenAI、Gemini 等，也可自定义地址。
3. 填写地址和密钥后自动获取模型列表，可在下拉框中搜索选择，也可手动输入模型 ID。点击“获取模型 / 刷新模型”可以重新拉取；部分厂商不提供列表接口或需要单独开通模型权限，仍可手填。
4. 可点击“测试连通性”验证当前表单，测试期间可以取消；测试不会自动保存配置，可能产生少量模型用量。模型列表仅表示服务返回的模型 ID，实际可用性以测试为准。
5. 点击“保存模型”。首个模型自动成为当前模型；后续可在左侧选择模型并点击“设为当前模型”。

编辑已有模型时，直接在左侧选择并修改后保存。同一服务地址和模型 ID 不会重复添加。

输出预算默认 4096 tokens，可按模型要求调整；部分推理模型会把思考也计入此预算。程序对已适配厂商使用各自的关闭思考参数，并区分思考耗尽预算、正文截断、空响应及内容过滤，失败结果不会作为成功内容保存。自定义中转地址使用通用协议，不会仅凭模型名称套用其他厂商的私有参数。更换厂商会清空旧密钥和模型 ID，避免把旧密钥发送到新服务。

AI 模型负责句子、图片和 PDF 选区翻译，也负责为单词生成助记内容。没有配置模型时，本地词典查询仍可使用，但 AI 翻译和助记不可用。

首次进入便捷模式时，欢迎区会提示本地查词与 AI 的可用状态。“试试本地查词”只使用离线词典，不请求 AI，也不保存查询历史；“配置 AI 模型”可直接打开模型设置。未配置有效模型时，句子和图片会保留输入并提示配置，不会发送 AI 请求。

## 外观与风格

在“设置 → 外观与风格”中，可选择星樱、夜航、晴空、松林，以及纳西妲、芙宁娜、雷电将军三款角色主题。原有四款主题配有星灵、月夜、云朵或叶灵装饰；角色主题使用新绘制的透明 Q 版阅读插画。插画用于空白页、主题预览和复习完成页，释义与译文保持纯色背景。选择后立即应用并记住偏好，覆盖便捷模式、设置、划词弹窗和 PDF 阅读器工具栏；PDF 纸张背景仍可独立选择。

## 使用便捷模式

### 查询单词

在输入框输入一个单词并稍作停顿，本地词典结果会自动出现。AI 内容将在网络请求完成后继续补充，不会阻塞基础词义。

单词结果出现后，窗口顶部会收紧，优先显示释义、语境、搭配和例句。近义词、易错提醒与记忆提示放在“更多学习内容”中，展开偏好会记住；折叠不影响完整复制、收藏或加入学习。

程序会先查询本地词典，停止输入约 800ms 后才请求 AI。可取消勾选主窗口中的“自动 AI 补充”，只在点击“查询单词”或按 `Ctrl+Enter` 时调用模型。编辑、清空或切换模型会取消旧请求；手动查询会停止自动计时，避免重复请求。单词输入区更紧凑，长句和图片自动展开。

输入过程中的快速本地预览不写入历史，避免把尚未输入完整的词片段保存下来。手动查询会保留已查到的本地释义，自动 AI 查询则在结果完成后保存。

### 查询历史与收藏

点击主窗口顶部的“历史与收藏”，可搜索原文、释义或译文，按单词、句子、图片筛选，并分页加载记录。选中后可离线预览或点击“重新打开”，不会再次调用 AI。删除历史不会删除收藏或学习计划，取消收藏也不会移除学习项目。历史记录不保存原图片；如需重新翻译图片，请重新粘贴。

在“查询历史”中点击“批量删除历史”，勾选要删除的条目，再点击“删除勾选”。可使用“全选已加载”或“取消全选”；加载更多后新增条目默认不勾选。删除前会确认数量，切换搜索或筛选条件会清除勾选。

### 查询失败后重试

失败时会保留输入和已有本地释义，点击“重试”可跳过旧缓存重新请求。也可先在模型下拉框中切换模型再重试。模型输出被截断时会明确提示，不会把不完整结果当作成功保存。

### 翻译句子

输入完整句子，按 `Ctrl+Enter` 或点击“开始学习”。

译文会随着模型生成逐步显示。等待本次翻译完成后，可点击“收藏”保存包含关键表达和学习提示的完整结果。

### 翻译图片

先复制一张图片，在 LinguaSpark 输入区域粘贴，然后按 `Ctrl+Enter`。图片内容会发送给当前配置的多模态模型。

### 翻译其他应用中的选中文字

在浏览器、Word 或其他应用中选择文字，按 `Alt+W`。如果当前正在使用 PDF 阅读模式且 PDF 中存在选区，`Alt+W` 会优先翻译 PDF 选区。

## 使用 PDF 阅读模式

1. 启动时选择“PDF 阅读模式”，或从系统托盘进入。
2. 点击“打开 PDF”，可以一次选择一个或多个文件。
3. 使用鼠标滚轮阅读；通过工具栏或 `Ctrl + 滚轮` 调整缩放。
4. 用鼠标拖动选择需要翻译的句子。
5. 按 `Alt+W` 或点击右侧“翻译”，译文与词组分析会显示在右侧。
6. 如需保留重点，选择颜色后点击“标记”或按 `Ctrl+H`；重新选择同一段文字，点击“移除标记”或按 `Ctrl+R` 可取消当前标记。可在“设置 → 快捷键”中修改这两个按键，保存并关闭设置后生效。快捷键仅在当前 PDF 标签中生效，专注阅读时也可使用。
7. 点击“专注阅读”隐藏工具栏和标签栏，按 `Esc` 恢复。

标记会保存到本地数据库，下次打开同一 PDF 时仍会显示。

词组分析中的每一项都可以“加入学习”。完整翻译成功后按钮才可用，保存内容包括词组、释义、所选原句、当时的译文及来源 PDF 页码；重复加入不会删除学习项目或重置复习进度。阅读器顶部的“复习”可打开已有复习系统，卡片中的“返回来源 PDF”会打开或复用原文标签并跳到来源页。来源路径只保存在本机，不会发送给模型；文件移动或删除后会提示恢复原位置。已有词条首次附加 PDF 来源时保留原有学习进度，后续再次遇到同一词条不会覆盖其首个 PDF 来源。

## 安装本地词典

项目使用 MIT 许可的 [ECDICT](https://github.com/skywind3000/ECDICT)。下载其 `ecdict.csv` 后，把文件拖到 `install_dictionary.bat` 上，脚本会筛选适合学习的高频词并生成 `data/ecdict_core.sqlite3`。

也可以从终端运行：

```bat
install_dictionary.bat C:\path\to\ecdict.csv
```

没有安装本地词典时，句子、图片和 PDF 翻译仍可使用，但单词不会显示离线基础释义。

## 发音设置

在“设置 → 学习与发音”中可以选择：

- 美式英语或英式英语发音。
- Windows 本地语音：离线可用，不需要额外密钥。
- Azure 神经语音：音质更自然，需要填写 Azure 区域和 Speech Key。
- 本地语速、学习语言、翻译语言、解释语言和每日复习提醒。

## 快捷键

| 快捷键 | 默认功能 |
| --- | --- |
| `Alt+Q` | 显示或隐藏便捷模式窗口；PDF 模式可用时会切换到便捷模式 |
| `Alt+W` | 翻译 PDF 当前选区，或读取系统当前选中文字 |
| `Ctrl+H` | 标记 PDF 当前选区，仅在当前 PDF 标签内生效 |
| `Ctrl+R` | 移除同一 PDF 选区的标记，仅在当前 PDF 标签内生效 |
| `Esc` | 退出 PDF 专注阅读 |
| `Ctrl+Enter` | 提交句子或图片 |
| `Ctrl+L` | 清空便捷模式当前内容 |

`Alt+Q`、`Alt+W`、PDF 标记和移除标记可以在“设置 → 快捷键”中重新录制。保存并关闭设置后，已打开的 PDF 标签同步更新。建议使用带有 `Ctrl`、`Alt`、`Shift` 或 `Win` 的组合键；不同功能不能设置为同一按键。

## 数据与隐私

- API Key 和 Azure Speech Key 使用当前 Windows 用户的 DPAPI 加密。
- 配置、历史、收藏、学习记录、标记、AI 缓存和性能指标保存在用户 AppData 目录，不会写入项目仓库。
- PDF 文件由本机 PDF.js 读取，只通过随机端口的 `127.0.0.1` 本地服务提供给阅读器，不会上传整个 PDF。
- PDF 翻译只向当前 AI 模型发送最终选中的文字及语言设置，不发送文件路径、全文或本地标记。
- 图片翻译会把粘贴的图片发送给当前配置的多模态模型，请避免处理包含敏感信息的图片。

## 当前限制

- PDF 阅读依赖文件自带的文字层，扫描版 PDF 暂不支持 OCR。
- 跨页选区可以翻译，但为避免保存错误坐标，不能创建跨页持久标记。
- PDF 密码、复杂权限限制或损坏文件可能无法正常打开。
- 当前项目主要面向英语学习；语言、词典、模型和界面已解耦，后续可以扩展为多语言学习助手。

## 测试与构建

运行测试：

```bat
test.bat
```

`test.bat` 使用 Qt 离屏后端。若 PDF.js 测试遇到显卡上下文丢失或 WebEngine 进程退出，可在有图形桌面的 Windows PowerShell 中使用正常窗口后端验证：

```powershell
$env:QT_QPA_PLATFORM = "windows"
.\.venv\Scripts\python.exe -m pytest -q
```

构建 Windows 可执行文件：

```bat
build.bat
```

构建结果位于 `dist\LinguaSpark\LinguaSpark.exe`。快速启动版会保留同目录运行文件，避免每次启动重复解压 Qt 与 PDF 阅读组件；构建脚本会包含代码、图标、PDF.js 资源和已经生成的本地词典，但不会包含 `config.json`、API 密钥、历史或缓存。

## 项目目录

- `learning_assistant/`：当前 PySide6 应用、PDF.js 适配、服务和存储。
- `tests_v2/`：当前回归测试；`tools/`：词典生成、迁移、构建和诊断工具。
- `assets/`：PDF.js、图标和主题资源；`data/`：离线词典。
- `artifacts/`、`build/`、`dist/`：本地诊断、构建及发布产物，不纳入新提交。
- 根目录的 `ui/`、`utils/`、`config.py`、`translator.py` 和旧 `learning_assistant/ui/pdf_view.py` 属于历史实现，当前入口和发布构建不引用。详细核查见 [文件用途审计](docs/file-audit-2026-11-10.md)。

详细的模块边界和扩展方式请参阅 [架构说明](docs/ARCHITECTURE.md)。第三方组件及许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
