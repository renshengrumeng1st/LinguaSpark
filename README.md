# LinguaSpark

LinguaSpark 是一款面向 Windows 的 AI 辅助英语学习助手。它既可以快速查询单词、翻译句子和图片，也可以在 PDF 文献中划选句子并即时获得译文与词组分析。

当前版本：`v2.2`

[下载 Windows 64 位发布包](https://github.com/renshengrumeng1st/LinguaSpark/releases/download/v2.2/LinguaSpark-v2.2-windows-x64.zip) · [版本发布记录](https://github.com/renshengrumeng1st/LinguaSpark/releases)

## v2.2 更新

- 新增 Windows 开机自启设置，登录后在系统托盘后台运行。
- 便捷模式的句子、图片和全局划词翻译支持流式显示译文，无需等待词组和学习提示全部生成。
- 译文生成期间暂不允许收藏，完成后再保存完整结果，修复流式期间收藏内容为空的问题。
- 修复流式译文中反斜杠、Unicode 转义和分块边界的处理。

## 主要功能

### 便捷学习模式

- **单词查询**：输入单词后自动查询本地词典，优先显示音标、词性、释义和词形，不必等待网络。
- **AI 助记**：随后由 AI 补充通俗解释、近义词、常用搭配、例句和记忆提示。
- **句子翻译**：输入句子后按 `Ctrl+Enter`，流式显示 AI 译文，再补充关键表达和学习提示。
- **图片翻译**：直接粘贴剪贴板图片，再按 `Ctrl+Enter` 识别并流式显示译文。
- **全局划词翻译**：在其他应用中选中文字后按 `Alt+W`，LinguaSpark 会优先通过 Windows UI Automation 读取选区，并在失败时安全回退到剪贴板。
- **发音**：支持离线 Windows 本地语音，也可配置音质更自然的 Azure Neural TTS。
- **学习与复习**：可以收藏内容、将单词加入学习计划，并使用“不记得 / 模糊 / 记得”完成间隔复习。
- **开机自启**：可在常规设置中开启，登录 Windows 后自动驻留托盘。

### PDF 阅读模式

- 同时打开多个 PDF，通过顶部标签快速切换。
- 鼠标滚轮连续阅读，支持 `50%–300%` 缩放、适合宽度和 `Ctrl + 滚轮` 缩放。
- 使用 PDF.js 原生文字层选择文本；拖动选区时直接显示蓝色高亮。
- 选中句子后按 `Alt+W`，右侧优先显示流式译文，随后补充最多 5 个词组分析。
- 支持黄色、绿色和粉色标记，也可以移除当前标记。
- 默认淡绿色护眼背景，可切换米黄、柔灰或白色主题。
- PDF 窗口默认最大化；点击“专注阅读”后只保留原文和译文栏，按 `Esc` 退出专注模式。
- 每个 PDF 标签独立保留滚动位置、缩放、选区、译文、词组分析和标记。

## 安装与启动

### 环境要求

- Windows 10 或 Windows 11（64 位）
- 一个兼容 OpenAI API 格式的 AI 模型服务

### 使用 Windows 发布包

1. 下载上方的 `LinguaSpark-v2.2-windows-x64.zip`。
2. 将压缩包完整解压到固定目录。
3. 双击 `LinguaSpark.exe` 启动，无需安装 Python。

请保留 EXE 同目录下的 `_internal` 文件夹，不要单独移动 EXE。发布包内已包含本地词典与 PDF 阅读组件。

升级时退出托盘中的旧程序，再使用新解压的完整目录。用户配置和学习数据保存在 AppData；如果更换了安装路径，请在新版本的常规设置中重新开启开机自启。

### 从源码运行

源码运行需要 Python，建议使用 Python 3.11 或更高版本。

克隆项目：

```bat
git clone https://github.com/renshengrumeng1st/LinguaSpark.git
cd LinguaSpark
```

首次使用先安装依赖：

```bat
setup.bat
```

安装完成后启动：

```bat
run.bat
```

启动时可以选择“便捷模式”或“PDF 阅读模式”。程序关闭窗口后仍会驻留在系统托盘，可通过托盘菜单重新打开模式选择、便捷模式、PDF 阅读模式或设置。

### 开机自动启动

打开“设置 → 常规”，勾选“开机时自动启动 LinguaSpark”，点击“保存常规设置”。此设置仅作用于当前 Windows 用户；自动启动时不弹出模式选择窗口，可通过系统托盘或快捷键打开界面。取消勾选并保存即可关闭。

## 首次配置 AI 模型

1. 打开“设置 → AI 模型”。
2. 填写显示名称、`Base URL`、`API Key` 和模型 ID。
3. 点击“保存模型”。
4. 在左侧选中刚添加的模型，然后点击“设为当前模型”。

AI 模型负责句子、图片和 PDF 选区翻译，也负责为单词生成助记内容。没有配置模型时，本地词典查询仍可使用，但 AI 翻译和助记不可用。

## 使用便捷模式

### 查询单词

在输入框输入一个单词并稍作停顿，本地词典结果会自动出现。AI 内容将在网络请求完成后继续补充，不会阻塞基础词义。

### 翻译句子

输入完整句子，按 `Ctrl+Enter` 或点击“开始学习”。

译文会随着模型生成逐步显示。等待本次翻译完成后，可点击“收藏”保存包含关键表达和学习提示的完整结果。

### 翻译图片

先复制一张图片，在 LinguaSpark 输入区域粘贴，然后按 `Ctrl+Enter`。图片内容会发送给当前配置的多模态模型。

### 翻译其他应用中的选中文字

在浏览器、Word 或其他应用中选择文字，按 `Alt+W`。如果当前正在使用 PDF 阅读模式且 PDF 中存在选区，`Alt+W` 会优先翻译 PDF 选区。

## 使用 PDF 阅读模式

1. 启动时选择“PDF 阅读模式”，或从系统托盘进入。
2. 点击“打开 PDF”，可以一次选择一个或多个文件。
3. 使用鼠标滚轮阅读；通过工具栏或 `Ctrl + 滚轮` 调整缩放。
4. 用鼠标拖动选择需要翻译的句子。
5. 按 `Alt+W` 或点击右侧“翻译”，译文与词组分析会显示在右侧。
6. 如需保留重点，选择颜色后点击“标记”；点击“移除标记”可取消当前标记。
7. 点击“专注阅读”隐藏工具栏和标签栏，按 `Esc` 恢复。

标记会保存到本地数据库，下次打开同一 PDF 时仍会显示。

## 安装本地词典

项目使用 MIT 许可的 [ECDICT](https://github.com/skywind3000/ECDICT)。下载其 `ecdict.csv` 后，把文件拖到 `install_dictionary.bat` 上，脚本会筛选适合学习的高频词并生成 `data/ecdict_core.sqlite3`。

也可以从终端运行：

```bat
install_dictionary.bat C:\path\to\ecdict.csv
```

没有安装本地词典时，句子、图片和 PDF 翻译仍可使用，但单词不会显示离线基础释义。

## 发音设置

在“设置 → 学习与发音”中可以选择：

- 美式英语或英式英语发音。
- Windows 本地语音：离线可用，不需要额外密钥。
- Azure 神经语音：音质更自然，需要填写 Azure 区域和 Speech Key。
- 本地语速、学习语言、翻译语言、解释语言和每日复习提醒。

## 快捷键

| 快捷键 | 默认功能 |
| --- | --- |
| `Alt+Q` | 显示或隐藏便捷模式窗口；PDF 模式可用时会切换到便捷模式 |
| `Alt+W` | 翻译 PDF 当前选区，或读取系统当前选中文字 |
| `Esc` | 退出 PDF 专注阅读 |
| `Ctrl+Enter` | 提交句子或图片 |
| `Ctrl+L` | 清空便捷模式当前内容 |

`Alt+Q` 和 `Alt+W` 可以在“设置 → 快捷键”中重新录制。建议使用带有 `Ctrl`、`Alt`、`Shift` 或 `Win` 的组合键，避免与普通输入冲突。

## 数据与隐私

- API Key 和 Azure Speech Key 使用当前 Windows 用户的 DPAPI 加密。
- 配置、历史、收藏、学习记录、标记、AI 缓存和性能指标保存在用户 AppData 目录，不会写入项目仓库。
- PDF 文件由本机 PDF.js 读取，只通过随机端口的 `127.0.0.1` 本地服务提供给阅读器，不会上传整个 PDF。
- PDF 翻译只向当前 AI 模型发送最终选中的文字及语言设置，不发送文件路径、全文或本地标记。
- 图片翻译会把粘贴的图片发送给当前配置的多模态模型，请避免处理包含敏感信息的图片。

## 当前限制

- PDF 阅读依赖文件自带的文字层，扫描版 PDF 暂不支持 OCR。
- 跨页选区可以翻译，但为避免保存错误坐标，不能创建跨页持久标记。
- PDF 密码、复杂权限限制或损坏文件可能无法正常打开。
- 当前项目主要面向英语学习；语言、词典、模型和界面已解耦，后续可以扩展为多语言学习助手。

## 测试与构建

运行测试：

```bat
test.bat
```

`test.bat` 使用 Qt 离屏后端。若 PDF.js 测试遇到显卡上下文丢失或 WebEngine 进程退出，可在有图形桌面的 Windows PowerShell 中使用正常窗口后端验证：

```powershell
$env:QT_QPA_PLATFORM = "windows"
.\.venv\Scripts\python.exe -m pytest -q
```

构建 Windows 可执行文件：

```bat
build.bat
```

构建结果位于 `dist\LinguaSpark\LinguaSpark.exe`。快速启动版会保留同目录运行文件，避免每次启动重复解压 Qt 与 PDF 阅读组件；构建脚本会包含代码、图标、PDF.js 资源和已经生成的本地词典，但不会包含 `config.json`、API 密钥、历史或缓存。

详细的模块边界和扩展方式请参阅 [架构说明](docs/ARCHITECTURE.md)。第三方组件及许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
